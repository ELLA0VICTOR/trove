# Trove functionality: implemented and remaining

Audited October 26, 2026. This is an implementation checklist, not an estimated judging score. The [official event](https://recall-tatum-walrus.vercel.app/) weights integration 30%, technical quality 30%, creativity 20%, and presentation 20%. It requires at least ten Mainnet Walrus memories, Tatum where relevant, a demo, a public repository, and a published blog post.

## Current integration milestone

Saved family sign-in, single-use learner invitations, parent consent, the Mainnet memory worker, scoped confirmed retrieval, correction-aware OpenAI replies, fresh-session recall and durable caching now work. Ten explicitly synthetic demo-learning records are confirmed on Mainnet. Total OpenAI estimate at the verified checkpoint was $0.0002884 including the earlier standalone test. Guest history remains local; prices remain authored samples and Sui practice transactions remain zero. See BUILD-STATUS.md for actual verification and limitations.

## Build in this order

1. **Verify providers.** Configure Tatum Testnet/Mainnet and Walrus Mainnet using [ACCOUNT-SETUP.md](ACCOUNT-SETUP.md). Prove real reads, then one non-sensitive write with durable acceptance, actual confirmation, and fresh-client recall. Save sanitized evidence. A successful connection is not a completed product integration.
2. **Replace preview authority.** Implement genuine parent/learner login, expiring sessions, membership/invites, server-verified signing, origin protections, and account-scoped retrieval. Keep the guest sample isolated. No live parent authority may depend on a role dropdown.
3. **Finish the Sui practice-account slice.** Implement/test the planned Move package, exact approvals and price-ticket trust boundary; deploy on Testnet and reconcile actions through Tatum. Record package/network, successful and refused actions, digests and source version. A custom contract is Trove's planned implementation, not a separate hackathon requirement.
4. **Connect useful persistent memory.** Only authorized eligible events enter the live worker. Finish confirmation/receipt links, scoped retrieval, correction/version filtering, expiry/removal and restart recovery. Show a fresh session recalling the original reason. Count ten distinct useful confirmed Mainnet records, never seeded examples or diagnostics.
5. **Replace sample market observations.** Verify provider history/display rights, cache immutable daily snapshots, handle splits/dividends consistently and reject incomplete data. Build actual transaction-ledger valuation separately from replay. Daily prices must carry their observation date and must not be advertised as real-time quotes.
6. **Connect and evaluate the coach.** Feed validated, active, authorized memory plus deterministic facts to a read-only model. Validate citations and exercise IDs. Compare remembered-history, no-history and corrected-history cases; test wrong-user retrieval and injected memory text. Save outcomes and failures with denominators, latency, model and cost.
7. **Deliver the submission.** Hosted repeatable demo, public sanitized repo, real integration evidence, published blog and short walkthrough. Verify requirements against the event at delivery time. Optional payments/AI Builder awards must not distract from the core loop.
